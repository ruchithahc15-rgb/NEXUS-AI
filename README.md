# NEXUS AI

Enterprise AI Operations & Decision Intelligence Platform.

NEXUS AI is an AI-powered enterprise investigation platform
designed to investigate business, engineering, and customer
operations problems.

## Core Use Cases

1. Business Intelligence Agent
   - Investigate why sales or revenue decreased.

2. Developer Operations Agent
   - Investigate the latest failed deployment.

3. Customer Operations Agent
   - Find customers with unresolved payment-related complaints.

## Technology Stack

- Python
- FastAPI
- React
- TypeScript
- PostgreSQL
- LangGraph
- Model Context Protocol (MCP)
